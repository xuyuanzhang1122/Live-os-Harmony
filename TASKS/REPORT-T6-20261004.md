## 实现说明

- 管理请求使用 Bearer；v2 媒体只使用短期 play_token。同源才带管理凭据，跨源媒体及缩略图不附带 Key。
- 仅证实旧端点不存在时允许 legacy 回退。JSON 404、鉴权错误、未知状态、无效字段、目录核验失败均明确报错。
- v2 清单缺少缩略图和时间，按路径从旧清单补展示字段，身份和统计仍以 v2 为准。房间、账号、设置、历史、备份继续管理 API。
- 刷新媒体先 prepared，再等 seekDone 恢复位置、倍速，最后按原意播放；暂停刷新不短暂出声。Go omitempty 省略 refresh=0 时仅在 token 硬过期边界归一化，其他缺失仍拒绝。
- 原 APIClient 接口保留；新增可选适配模式参数和 v2 方法。新增本地 libavcap.so 为工程自有 NDK 模块，无运行时三方依赖。
- 独立审查发现近过期刷新、缺身份删除、暂停刷新三项问题，均先复现再修复。另由真实设备发现 AAC profile 空数组，再补 C++ 查询回归。
- 签名材料由用户在另一份同名工程配置，合法签名仅复制到权限受限的临时构建副本；仓库工程级签名配置不改，不提交任何证书、口令、私钥、HAP 或真机原始日志。
- 真机诊断包新增仅内存的测试 APIClient、测试入口和定时驱动；播放器/网络/会话/能力业务源码与仓库一致。定时驱动调用真实 Controller 的 seek/pause/play，不等同于手动拖动手势验收。交付包使用常规入口，并核对源文件字节一致。
- 测试服务只监听 127.0.0.1:18686，独立输出/数据库/缓存/配置，通过 HDC 反向端口访问。未改远端生产、未 push、未进行真实历史批量转换。
